# assets

Images publiques des applications Arkéa SDM (favicons, icônes).
Ne rien déposer ici de confidentiel : le dépôt est public.

## Signature DocuSign

| Fichier | Usage |
| --- | --- |
| [`signature-docusign/favicon.png`](signature-docusign/favicon.png) | Favicon (64 px), à coller dans le réglage `FAVICON_URL` |
| `signature-docusign/favicon-32.png`, `icon-192.png`, `icon-512.png` | Autres tailles |
| `signature-docusign/icon.svg` | Source vectorielle |

Lien direct : `https://raw.githubusercontent.com/ArkeaSDM/assets/main/signature-docusign/favicon.png`

## Hub de données

| Fichier | Usage |
| --- | --- |
| [`data-hub/favicon.png`](data-hub/favicon.png) | Favicon (64 px), utilisé par `doGet()` du Data-Hub |
| `data-hub/favicon-32.png`, `icon-192.png` | Autres tailles (`icon-192.png` sert au logo de l'en-tête) |
| `data-hub/icon-512.png` | Grande taille |
| `data-hub/icon.svg` | Source vectorielle |

Lien direct : `https://raw.githubusercontent.com/ArkeaSDM/assets/main/data-hub/favicon.png`
